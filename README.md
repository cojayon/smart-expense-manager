# Smart Expense Manager

A simple and practical web application for managingpersonal expenses.

## Features
- Add expenses
- Search expenses
- Delete expenses
- Calculate total expenses
- View expense statistics
- Store data in the browser using Local Storage
- Responsive design for different screen sizes  

## Technologies
- HTML 
- CSS 
- JavaScript 
- Python
                
 ## Project Goal
The goal of this project is to provide a simple way to record,
manage, and analyze daily expenses.
